# 🏋️‍♂️ AI-Powered Gym Member Churn Analytics & Retention Platform

An end-to-end Machine Learning web application built with **Python** and **Streamlit** designed specifically for fitness clubs and gyms (such as boutique training facilities) to predict member drop-offs, evaluate retention risks, and export actionable analytics reports.

## 🚀 Features
* **Real-time Churn Prediction:** Predicts the likelihood of a member canceling their subscription based on attendance patterns, workout duration, and last visit metrics.
* **Interactive Dashboard:** Clean, modern UI displaying key performance indicators (KPIs) like total active members, at-risk members, and overall churn rates.
* **Custom Dataset Support:** Upload custom gym CSV data to evaluate retention metrics instantly.
* **Automated Action Reporting:** Export detailed analytical CSV reports containing high-risk member insights for management review.
* **Cloud-Ready:** Lightweight single-file architecture optimized for fast deployment on Streamlit Cloud.

## 🛠️ Tech Stack
* **Python** (Core Logic)
* **Streamlit** (Interactive UI & Frontend)
* **Scikit-Learn** (Random Forest Machine Learning Model)
* **Pandas & NumPy** (Data Processing & Simulation)
